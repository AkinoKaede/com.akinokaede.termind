# Termind design assets

- `brand/termind.svg`: master brand mark with white windows, gray outlines
  (#6C7A83), and a blue terminal chevron (#38B6F4).
- `paywall/`: light and dark feature illustrations.
- `../public/brand_mark.svg` and `../public/favicon.svg`: website variants.

Preserve transparency and white window fills. Do not add a platform icon mask.

## Website style

Use white surfaces on #F7F9FA, #26343D text, #38B6F4 accents, and #086A9B for
readable blue text and focus outlines. Headings use Iowan Old Style / Palatino
and Songti SC; body text uses Avenir Next and PingFang SC.

Check all three languages, narrow screens, keyboard focus, and reduced motion.
These guidelines grant no additional rights to use or redistribute Termind branding.
