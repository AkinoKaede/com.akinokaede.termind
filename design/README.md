# Termind design assets

- `brand/termind.svg`: master brand mark with white windows, gray outlines
  (#6C7A83), and a blue terminal chevron (#38B6F4).
- `paywall/`: light and dark feature illustrations.
- `../public/brand_mark.svg` and `../public/favicon.svg`: website variants.

Preserve transparency and white window fills. Do not add a platform icon mask.

## Website style

Use white backgrounds and solid #EDF3F7 panels, #26343D text, #38B6F4 accents,
and #086A9B for readable blue text and focus outlines. Avoid gradients.
English headings use Palatino and body text uses Avenir Next. Chinese uses
PingFang SC/TC; Japanese uses Hiragino Sans; Korean uses Apple SD Gothic Neo.
CJK side headlines in App Store artwork use upright vertical text, including
vertical punctuation where needed. Korean stacks complete Hangul syllables,
not individual jamo. German and French reuse the English Palatino/SF Pro
hierarchy and rotated side headlines, with localized line breaks.

Check English, German, French, Japanese, Korean, Simplified Chinese,
and Traditional Chinese landing pages, along with narrow screens, keyboard focus,
and reduced motion. Figma boards marked `DRAFT - native capture pending` are
not ready for App Store delivery; never export fallback-language artwork as
a finished localized screenshot.
